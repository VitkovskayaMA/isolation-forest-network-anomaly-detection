## Описание проекта

Программная реализация модели обнаружения сетевых аномалий на основе алгоритма Isolation Forest.

В качестве набора данных используется датасет UNSW-NB15. Выполняется предварительная обработка данных, кодирование категориальных признаков, масштабирование признаков с помощью RobustScaler, обучение модели Isolation Forest и оценка качества обнаружения аномалий.
